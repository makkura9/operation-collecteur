# Opération Collecteur — site pédagogique

Site fictif utilisé en classe pour apprendre la sécurité informatique par l'enquête.

- Aucune donnée n'est collectée : pas de serveur, pas de formulaire envoyé, pas d'outil de mesure d'audience. Seul le navigateur mémorise la progression (sur l'ordinateur utilisé).
- Aucun lien ne mène hors du site, et rien n'est chargé depuis un service externe.
- Les personnes, les marques, les lieux et les sites présentés sont inventés.

Environnement pédagogique fictif — toute ressemblance avec des personnes ou des services réels serait fortuite.
